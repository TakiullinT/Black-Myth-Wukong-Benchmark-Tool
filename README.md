# Black Myth: Wukong - Benchmark Automation Tool

Консольная утилита на C# (.NET) для автоматизации прогона официального бенчмарка игры **Black Myth: Wukong**, динамического управления графическими пресетами под тесты процессора и видеокарты, а также автоматического считывания результатов с экрана с помощью OCR.

---

## 🚀 Основные особенности

- **Умное управление INI-файлами UE5 (`ConfigManager`):** Автоматическая генерация и обновление `GameUserSettings.ini` в директории движка Unreal Engine. Позволяет на лету менять разрешении (1920x1200), пресеты графики и параметры апскейла (TSR/FSR) для раздельного тестирования CPU и GPU.
- **Интегрированный OCR-парсер (`OcrHelper`):** Поскольку игра не выводит результаты в текстовые логи, утилита делает скриншот экрана по окончании сцены и распознает итоговые показатели FPS с помощью встроенного системного API Windows (`Windows.Media.Ocr`).
- **Контроль жизненного цикла процесса (`BenchmarkRunner`):** Запуск бенчмарка через протокол Steam URI (`steam://run/3132990`), динамический мониторинг запущенного процесса (`b1-Win64-Shipping`), безопасные таймауты и принудительная очистка сессии с паузами для корректного взаимодействия со Steam.
- **Аппаратное профилирование (`HardwareInfo` & `SystemInfoPrinter`):** Автоматическое определение модели процессора, видеокарты (с приоритетом дискретных решений NVIDIA/AMD над встроенной графикой) и объема оперативной памяти через WMI.
- **Кроссплатформенная разработка:** Поддержка отладки и компиляции на macOS благодаря встроенным заглушкам и проверкам среды выполнения (`OperatingSystem.IsWindows()`).

---

## 🛠️ Технологический стек

- **Язык:** C# (.NET)
- **Основные библиотеки и API:**
  - `Windows.Media.Ocr` & `Windows.Graphics.Imaging` (оптическое распознавание текста с экрана)
  - `System.Management` (WMI-запросы для сбора характеристик ПК)
  - `System.Text.RegularExpressions` (парсинг строк с результатами FPS)
- **Архитектура:** Модульные статические утилитные классы, разделение ответственности между конфигами, запуском, OCR и сбором железа.

## 📂 Структура проекта

```text
WukongBenchmarkAutomation/
│
├── Program.cs             # Оркестрация пайплайна (CPU-тест -> GPU-тест -> Итоговый отчет)
├── ConfigManager.cs       # Управление разрешением и пресетами в GameUserSettings.ini
├── BenchmarkRunner.cs     # Запуск через Steam URI, мониторинг процесса и синхронизация
├── OcrHelper.cs           # Захват экрана и распознавание FPS через Windows OCR
├── HardwareInfo.cs        # WMI-запросы для сбора данных о CPU, GPU и RAM
└── SystemInfoPrinter.cs   # Форматирование и вывод характеристик и итогов в консоль

```

## ⚙️ Как работает пайплайн

1. **Инициализация:**
* Считывание и вывод характеристик компьютера (`CPU`, `GPU`, `RAM`) в шапке консоли.


2. **CPU-тест (Процессор):**
* Применение легких настроек через `ConfigManager` (1920x1200, пресет Low + агрессивный Upscaling для снятия нагрузки с видеокарты).
* Запуск бенчмарка, ожидание прогона и динамический опрос экрана через OCR для фиксации среднего FPS.


3. **GPU-тест (Видеокарта):**
* Применение сбалансированных настроек (1920x1200, пресет Medium).
* Повторный запуск и замер производительности видеокарты.


4. **Итоговый отчет:**
* Вывод сравнительной таблицы результатов в консоль и завершение работы.

## 💻 Быстрый старт

### Требования

* **ОС:** Windows 10/11 (необходимо для работы OCR-модуля Windows и WMI; на macOS доступен режим разработки с заглушками).
* **Среда выполнения:** .NET SDK.
* **Игра:** Установленный *Black Myth: Wukong Benchmark Tool* в Steam.

### Запуск проекта

1. Клонируйте репозиторий:

```bash
cd Black-Myth-Wukong-Benchmark-Tool

```


3. Запустите приложение:
